# 启动文档

这份文档只讲怎么把项目跑起来。项目是做什么的，看仓库根目录的 [README](../../README.md)。改代码看 [开发文档](开发文档.md)。

## 最快的一条路

在已经装好 Go、Node.js、MySQL、HBuilderX 的机器上：

1. 确认 MySQL 里已有库 `smam_sql`。没有就按下面的「第一次导入数据库」导入。
2. 双击仓库根目录的 `一键启动新后端.bat`。
3. 打开 http://127.0.0.1:8088/health ，返回里有 ok，再打开管理后台 http://127.0.0.1:5173/#/admin/login 。

## 需要装好的东西

- Go 1.23 或更高
- Node.js，用来跑管理后台
- MySQL 5.7
- HBuilderX，用来跑用户端和技师端

这台开发机上的路径是：

- MySQL：`D:\phpenv\server\mysql\mysql-5.7`
- HBuilderX 命令行：`D:\Program Files\HBuilderX\cli.exe`

数据库默认是本机 `127.0.0.1:3306`，库名 `smam_sql`，用户 `root`，密码 `root`。换机器时用环境变量改，变量表在开发文档里。

## 第一次导入数据库

库已经存在就不用再导。换一台机器时，先建库再导入：

```bat
mysql -uroot -proot -e "CREATE DATABASE IF NOT EXISTS smam_sql DEFAULT CHARSET utf8mb4;"
mysql -uroot -proot --default-character-set=utf8mb4 smam_sql < dev\smam_sql.sql
```

导出文件是 `dev/smam_sql.sql`。里面的 `cd_log` 只保留表结构，原来的后台访问日志没有放进来。财务流水在 `cd_user_log`，那不是访问日志，数据还在。

## 一键启动

在仓库根目录双击，或者在命令行运行：

```bat
一键启动新后端.bat
```

脚本会按这个顺序做：

1. 确认 MySQL 在 3306 上。没起来就用上面那个 MySQL 5.7 启动。
2. 确认 8088 没被占用。
3. 在 `dev\server` 编译 `bin\server.exe` 并启动。上传目录指向 `dev\uploads`。
4. 在 `dev\admin` 执行 `npm run dev`。
5. 用 HBuilderX 把用户端、技师端运行到浏览器。

停掉 Go 和管理后台：

```bat
停止新后端.bat
```

## 分开启动

接口：

```bat
cd /d D:\work\dongjiaodaojia\dev\server
go build -o bin\server.exe ./cmd/server
set DJ_HTTP_ADDR=:8088
set DJ_UPLOAD_ROOT=D:\work\dongjiaodaojia\dev\uploads
bin\server.exe
```

看到 `dongjiao go server listening :8088` 后，打开 http://127.0.0.1:8088/health ，返回里有 ok 就说明接口好了。

管理后台：

```bat
cd /d D:\work\dongjiaodaojia\dev\admin
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/#/admin/login 。

用户端和技师端用 HBuilderX 打开这两个目录，选择「运行到浏览器」：

- `dev\user`
- `dev\tech`

HBuilderX 会自己分配端口。技师端这台机器上通常是 http://localhost:8080/h5/ 。两个端不要抢同一个端口。

## 打开后用哪个账号

| 端 | 地址 | 账号 |
| --- | --- | --- |
| 管理后台 | http://127.0.0.1:5173/#/admin/login | `admin` / `admin123` |
| 技师端 | HBuilderX 打开的地址 | 手机号 `13800138000`，验证码 `888888` |
| 用户端 | HBuilderX 打开的地址 | 验证码固定是 `888888` |

技师账号如果库里已经有这个手机号，登录不会再核对短信，填 `888888` 即可。

## 接口重启后要重新登录

技师端和用户端的登录令牌只放在 Go 进程的内存里。`停止新后端.bat`、重新编译、或者一键启动把进程杀掉之后，旧令牌失效，页面会提示先登录。这是正常的，重新登录一次就行。

## 端口对照

| 端口 | 谁在用 |
| --- | --- |
| 3306 | MySQL |
| 8088 | Go 接口 |
| 5173 | 管理后台 |
| 8080 左右 | HBuilderX 给用户端或技师端的网页 |
