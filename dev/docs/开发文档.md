# 开发文档

日常改的是 `dev` 下面四块。`backend` 和 `frontweb` 是旧 PHP 和旧前端，查原来的行为时再看，不要在那边继续加功能。

## 请求怎么走

三个前端都打到 Go：

```text
http://127.0.0.1:8088/public/index.php/{端}/{控制器}/{方法}
```

端只有三个：

| 端 | 路径开头 | 代码 |
| --- | --- | --- |
| 用户 | `/public/index.php/api/...` | `dev/server/internal/api` |
| 技师 | `/public/index.php/technician/...` | `dev/server/internal/tech` |
| 管理后台 | `/public/index.php/admin/...` | `dev/server/internal/admin` |

返回是 JSON：`code` 为 1 表示成功，`msg` 是提示，`data` 是内容。登录成功时 `data` 就是令牌字符串。请求头里的令牌字段名是 `token`。

管理后台的 Vite 把 `/public` 代理到 `127.0.0.1:8088`，所以页面里写相对路径即可。用户端和技师端在各自的请求文件里写死了 `http://127.0.0.1:8088`。

## 改完要怎么生效

- Go：在 `dev/server` 执行 `go build -o bin/server.exe ./cmd/server`，停掉旧进程再启动。不要在仓库根目录编译，根目录没有 Go 文件。重启后所有人要重新登录。
- 管理后台：`npm run dev` 开着时，保存 Vue 文件会自己刷新。
- 用户端、技师端：HBuilderX 开着时，保存 `.vue` 会重新编译到浏览器。H5 页面不要调用 `plus.*`，那是 App 才有的接口。

## 数据库

库名 `smam_sql`，表前缀 `cd_`。连接默认值写在 `dev/server/internal/config/config.go`，可以用环境变量改：

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `DJ_HTTP_ADDR` | `:8088` | 监听地址 |
| `DJ_DB_HOST` | `127.0.0.1` | 数据库主机 |
| `DJ_DB_PORT` | `3306` | 数据库端口 |
| `DJ_DB_USER` | `root` | 数据库用户 |
| `DJ_DB_PASS` | `root` | 数据库密码 |
| `DJ_DB_NAME` | `smam_sql` | 库名 |
| `DJ_DB_PREFIX` | `cd_` | 表前缀 |
| `DJ_UPLOAD_ROOT` | `../../backend/public/uploads` | 上传文件目录，相对 Go 进程的工作目录 |
| `DJ_PUBLIC_DOMAIN` | 空 | 图片地址用的域名。空着就用请求里的 Host |

当前库的导出在 `dev/smam_sql.sql`。`cd_log` 是后台每次打开页面记的访问日志，导出时把这些数据删了，表还在。`cd_user_log` 是订单、充值、提现的流水，保留着。

图片上传后放在 `backend/public/uploads`，接口通过 `/uploads/` 提供访问。

## 订单

`cd_order.order_status`：

| 值 | 含义 |
| --- | --- |
| 0 | 未支付 |
| 1 | 新订单 |
| 2 | 待服务 |
| 3 | 进行中 |
| 4 | 已完成 |
| 5 | 已评价 |
| 6 | 已取消 |

技师首页「新订单」看的是状态 1。列表接口返回 `{list, total, page}`，页面读 `data.list`。

技师这笔订单能拿多少，在用户支付时按项目规格上的「技师分成」算：

```text
技师收入 = 订单总价 × service_spec.technician_rate / 100
```

`technician_rate` 是百分数。项目分成是 1，总价 33，技师收入就是 0.33。分成是 0，收入就是 0。算好的数写进 `order.technician_money`，之后改项目分成不会回头改旧订单。技师等级不再参与这笔计算。

## 技师资料

身份认证 `cd_technician_identity.status`：没有照片是未提交，0 是认证中，1 是通过，2 是未通过。账号上的 `technician.status` 是另一件事，不要和某一项资料的审核状态混在一起。

服务时间存在 `technician.week`、`start_time`、`end_time`。时间用半小时一格的数字：整点是 `小时 × 2`，半点再加 1。例如 9:00 是 18，18:30 是 37。星期里 1 到 6 是周一到周六，0 是周日。

服务区域签到写入 `province`、`city`、`district`、`address`、`lat`、`lng`、`radius`。经纬度字段最长 15 个字符。技师端「我的」里下面那一行服务区域显示的是城市；城市空着就会显示「未设置」，哪怕区县已经有了。

## 地图

用户端设置上门地址、技师端签到选位置，用的是同一套高德 Key，写在选点组件里。高德搜索结果里的 `city` 有时是空数组，选点时要把它当成没有城市，再从地址文字里拆出城市，否则城市存不进去。

技师端 `manifest.json` 里还有一把腾讯地图 Key，H5 的 `uni.chooseLocation` 会用它。这把 Key 已经失效，浏览器里选位置不要再走腾讯。

## 管理后台列表

技师列表如果直接按一对多的表去 JOIN，一个技师有多条资料时会出现重复行。列表查询在关联不是主表 `id` 时，只连接子表里每个技师最大的那条记录。

## 本地验证

改了页面之后，用浏览器把那条操作走一遍：打开页面、点按钮、看接口是不是 200、刷新后数据还在。只看截图不够。

Go 改完必须重启进程。重启前先看 8088 上的旧进程，停掉再启动，工作目录要是 `dev\server`。
